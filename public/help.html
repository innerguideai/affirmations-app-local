Quick guidance for using the app.

Quick help
AI Affirm is a simple check-in. Tap an emotion to see an affirmation. Save what helps you and come back daily.

How to use

  • On Profile, tap an emotion (or use Other).
  • Read the affirmation and rate it if you want.
  • Use “Next Affirmation” to cycle.
  • Use Themes to change your background look.

Common issues

  • If a page looks stale, do a hard refresh once.
  • If Guest keeps bouncing, restart the app and try Guest again.
  • If a link doesn’t open, try again after the page fully loads.
